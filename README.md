# SEN - Hunt The Mad One

How to install and run:

1. Download the project files from GitHub
2. Open the downloaded files in a terminal (e.g. cmd)
3. Run the command "python -m venv .venv"
4. Depending on your operating system and terminal, use one of the following commands:
   - Windows PowerShell: .venv\Scripts\Activate.ps1
   - Windows CMD: .venv\Scripts\activate.bat
   - Git Bash (Windows): source .venv/Scripts/activate
   - Mac/Linux: source .venv/bin/activate
5. Once that has successfuly run, use "pip install -r /requirements.txt"
6. You should now be able to run the project with "python scripts/sen.py"
7. I would recommend using the "help" command once in the game if you aren't sure what to do.
